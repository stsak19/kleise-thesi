## Ιδέες για την εφαρμογή (δεν έχουν αποφασιστεί)
- **Στατιστικά επιχείρησης**: κρατήσεις ανά εβδομάδα, πιο γεμάτες ώρες, «δεν ήρθε», έσοδα πακέτων.
- **Εγκατάσταση της ιστοσελίδας ως εφαρμογή (PWA)**: εικονίδιο στην αρχική οθόνη του κινητού χωρίς store.
- **Αγγλικά** ως δεύτερη γλώσσα (τουρίστες, ξένοι πελάτες).
- **Προσβασιμότητα**: `accessibilityLabel` στα κουμπιά-εικονίδια (♥, ⓘ, ＋, ‹).

## Ιδέες για το repo (δεν έχουν αποφασιστεί)
- **Ξεχωριστή βάση για τις προεπισκοπήσεις** των PR (δεύτερο project Supabase ή Branching). Τώρα μιλάνε με την κανονική βάση. Θέλει τον Στάθη.
- **Αυτόματο τρέξιμο migrations** μετά το Merge (`supabase db push` σε Action). Θέλει access token της Supabase ως secret, άρα τον Στάθη.
- **Πίνακας με τα migrations που έχουν τρέξει** στη βάση, ώστε το `npm run allages` να λέει «το 022 δεν έχει τρέξει ακόμα».
- **Sentry** (αν χρειαστεί κάτι παραπάνω από τα «Σφάλματα» του super admin, 024): θέλει λογαριασμό και DSN.
- **EAS Build** για Play Store / App Store όταν έρθει η ώρα (υπάρχει ήδη `eas.json`).
- **Πραγματικά screenshots στο README** όταν υπάρχουν αληθινά καταστήματα (όχι ψεύτικα δεδομένα).
