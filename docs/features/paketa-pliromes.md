# Πακέτα και πληρωμές

## Πακέτα (004, 013, 015)
- Ο ιδιοκτήτης φτιάχνει πακέτα (όνομα, τιμή, επισκέψεις, μέρες)· συνδρομή χωρίς αριθμό = απεριόριστες. Οι επισκέψεις αφαιρούνται μία μία στις κρατήσεις (`memberships.credits`).
- Ο πελάτης πατά «Το θέλω». Πληρωμή στο κατάστημα → ο ιδιοκτήτης πατά «Πληρώθηκε» / «Δώσε πακέτο». Ή πληρωμή μέσα στην εφαρμογή (παρακάτω).
- Πακέτο για συγκεκριμένα μαθήματα (`packages.service_ids`, 015)· κενό = όλα.
- Ιστορικό: κάθε αντικατάσταση πακέτου πάει στο `pack_history` (trigger, 013).
- Οθόνες: `app/(biz)/owner/plans.tsx`, `lib/owner/packs.tsx`, `lib/store/Packs.tsx`, `lib/bookings/PackList.tsx`.

## Πληρωμή μέσα στην εφαρμογή
- **Τώρα: δοκιμαστική** (019, `pay_mode = 'test'`): `app/checkout.tsx` δείχνει κάρτα / Apple Pay / Google Pay → «Πληρώθηκε» → το πακέτο ενεργοποιείται. **Δεν χρεώνεται τίποτα.** Γράφεται στο `payments` με `test=true` και υπολογίζεται η προμήθεια.
- **Αργότερα: Viva** (018): Edge Functions `supabase/functions/viva-pay` και `viva-webhook`, λογαριασμός ISV της πλατφόρμας· τα χρήματα πάνε στον λογαριασμό Viva του καταστήματος και η προμήθεια (`isvAmount`) στην πλατφόρμα. Secrets: `VIVA_ENV`, `VIVA_CLIENT_ID`, `VIVA_CLIENT_SECRET`, `VIVA_SOURCE_CODE` (μόνο στη Supabase, ποτέ στο repo).
- Ενεργοποίηση της Viva: /admin → Πληρωμές → «Viva (πραγματικές)».
- Επιστροφή από πληρωμή: `app/paid.tsx` (επιβεβαιώνει με `viva-pay confirm`). Client: `lib/pay.ts`.
