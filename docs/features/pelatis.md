# Πελάτης

Φάκελος `app/(tabs)/`, κομμάτια στα `lib/client/`, `lib/bookings/`, `lib/profile/`.

- **Αρχική** `(search)/index.tsx`: κινητό = κενή με «Τι ψάχνεις;» και 8 κατηγορίες· υπολογιστής = πλακίδια και ενότητες. Αναζήτηση με είδος/πόλη (`lib/client/search.ts`: κάθε λέξη σε όνομα, πόλη, διεύθυνση, είδος).
- **Αγαπημένα** (migration 012): καρδιά στο κατάστημα, εμφανίζονται στην αρχική (`lib/favorites.ts`, `lib/client/FavRow.tsx`).
- **Κρατήσεις** `bookings.tsx`: Κρατήσεις | Πακέτα, και Ιστορικό σε πλαίσιο που ανοίγει (`lib/bookings/`, ιστορικό πακέτων migration 013). «Το συνηθισμένο σου» ψάχνει μία εβδομάδα τη φορά.
- **Υπενθύμιση ραντεβού** (migration 022): το cron `booking-reminders` (κάθε 15') γράφει ειδοποίηση στις Κρατήσεις πριν από κάθε ραντεβού. Προεπιλογή 24 ώρες πριν· ο πελάτης το αλλάζει/κλείνει στις Ρυθμίσεις → Ειδοποιήσεις (γράφεται στο `profiles.remind_min`, null = όχι). Μία φορά ανά κράτηση (`bookings.reminded_at`, μηδενίζεται αν αλλάξει η ώρα). Push: όταν μπει `push_token`, στέλνεται από το ίδιο σημείο (`send_booking_reminders`).
- **Προφίλ** `(profile)/`: Προφίλ, «Τα στοιχεία μου», Ρυθμίσεις, «Η δουλειά μου» για υπαλλήλους.
- **Επισκέπτης** (`lib/guest.ts`): βλέπει αρχική και καταστήματα χωρίς λογαριασμό· σύνδεση ζητιέται μόνο στην κράτηση ή στις Κρατήσεις/Προφίλ, και μετά γυρίζει εκεί που ήταν.
- Παλιές διευθύνσεις `packs.tsx`, `(search)/business/[id].tsx`: απλώς ανακατευθύνουν.
