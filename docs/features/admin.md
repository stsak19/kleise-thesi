# Super admin (010)

- Μόνο όσοι είναι στο `platform_admins` (ο πρώτος μπαίνει με το χέρι στο SQL Editor· **ποτέ email στο repo**).
- Όλες οι ενέργειες μόνο μέσω `admin_*` συναρτήσεων που ελέγχουν `is_super_admin()`. Κανένα service key στην εφαρμογή.
- Οθόνες `app/admin/`: Επισκόπηση, Καταστήματα (+ `shop/[id]`), Πελάτες (+ `person/[id]`), Κρατήσεις, Βαθμολογίες, Αιτήσεις διαγραφής, Πληρωμές. Μενού και κομμάτια: `lib/admin/parts.tsx`, δεδομένα `lib/admin/data.ts`.
